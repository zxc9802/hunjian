# 制作记录和音乐管理

- 选择制作记录后，可点击“暂停制作”。排队任务立即暂停；运行任务在当前步骤结束后的检查点暂停，显示“正在暂停”期间请等待。已提交的外部配音、检查请求继续完成，保存的配音任务 ID 和中间文件供继续制作复用。
- “从保存进度继续”恢复暂停、失败或中断任务。暂停记录不会被三天自动清理规则移除。
- “删除记录及成片”需要确认，会删除该任务 `video-jobs/<NAS任务ID>/` 下的全部 COS 成片版本、NAS 生成目录、工作台缓存和文字草稿。素材库原片保留。正在制作的任务先暂停；正在导出文字新版时等待导出完成。
- 删除出错时保留“删除未完成”记录，禁止继续制作和成片下载，可重试删除。已删除任务的提交标识不可复用，防止旧提交重试重新生成任务。
- 音乐库每首音乐旁的“删除”会删除 COS 音乐文件。仍被未完成任务（包括暂停、失败、中断任务）引用的音乐不能删除。已完成成片中混好的配乐不受影响。旧页面再次提交已删除音乐会被拒绝，需重新选择。

测试使用临时目录和临时 COS 对象；不删除用户已有制作记录或音乐。
